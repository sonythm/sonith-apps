Android app downloads

Install a test build straight from a file, with checksums so you can verify it.

I am Sonith, an independent developer in India. These are 24 small Android apps that I have built. They have no ads, no accounts, and keep your data on your phone. Some of them are not yet on Google Play, so for now you can install them straight from a file (an APK). This page lists each one with its checksum so you can confirm that the file you got is the file I made.

Please read: these are version 0.1.0 test builds. They work, but expect rough edges. Because your data lives only on your phone, uninstalling an app deletes its data. If an app has an export or backup option, use it before you uninstall or switch to another version.

Who can install these

  • Phones running Android 7.0 or newer (the apps need API 24 or higher).
  • Almost all phones sold since 2017 (64-bit ARM, called arm64-v8a). Most of the apps are built for that CPU type only, so they will not install on a 32-bit-only phone or on an x86 device or emulator. The two MySpend files include all CPU types.
  • Free. No payment, no sign-up, no ads, no tracking on this page (no analytics, no trackers and no external fonts; the only script is a small one that runs the menu).

How to install

  1. On your phone, tap an app's Download APK button below. The file is about 40 to 70 MB, so use Wi-Fi if you can. Your browser may say "this type of file can harm your device". That is a standard message for every APK.
  2. Check the file (recommended). Compare the SHA-256 shown on this page with the file's hash (see "Verifying the file" below). If they differ, do not install it.
  3. Open the downloaded file. Android will say it cannot install apps from this source. Tap Settings and switch on Allow from this source (also called Install unknown apps) for the browser or Files app you used. Go back and tap Install. The path on most phones is Settings, Apps, Special access, Install unknown apps. The wording differs between phone brands.
  4. Play Protect prompt. Android may show "Unrecognized developer" or "App scan recommended" or "Google Play Protect blocked this app". It appears because the app does not come from Google Play and its developer (me) has no history that Google recognises. It does not mean the file is infected. Tap More details, then Install anyway (or Scan app, then install). Only do this if the file's SHA-256 matches the one on this page. Do not turn Play Protect off.
  5. Open the app. Afterwards you can switch "Install unknown apps" off again for the browser.

Verifying the file on the phone

  • In a hash-checker app (any "hash" or "checksum" tool from a source you trust, or a file manager that shows file checksums), choose the downloaded file, choose SHA-256, and compare it with the value under Full SHA-256 on this page. Compare every character, or at least the first and last 12.
  • If you use a computer: certutil -hashfile file.apk SHA256 on Windows, or sha256sum file.apk on Linux and Mac. SHA256SUMS.txt lists every file.
  • A matching hash proves the file is unchanged since I published it. It does not prove anything about me; that is your call. If you do not feel comfortable, do not install.

Updating

Sideloaded apps do not update themselves. When a new version is announced, download the new file from this page and open it. Because every file uses the same package name and the same signing key, Android installs it over the old one and keeps your data. You do not need to uninstall first.

Important: sideloading and the Google Play version

The key caveat. These files are signed with my upload key. When an app goes live on Google Play, Google re-signs it with its own app-signing key. Android refuses to update an app when the signing key differs. So if you install an APK from this page, you cannot later update to the Play version; you would have to uninstall first, which deletes the app's data on your phone unless you export it first. If you can wait, install from Google Play once the app is listed there. If you do install the APK, use the app's export or backup option regularly.

Honest limitations

  • Version 0.1.0 test builds from a single developer. Bugs are likely. Tell me about them: sonythm@gmail.com.
  • Apps work offline and have no accounts. That also means no cloud backup and no sync: if you lose or reset the phone, the data is gone unless you exported it.
  • A few apps use the camera, microphone, contacts or calendar when you ask them to. Each privacy policy says exactly what and why. A few apps use the internet only for the one feature that needs it, and say so.
  • These builds have not been reviewed by Google, because they are not distributed through Google Play.
  • Files are hosted on GitHub Releases. This page is a static page with no tracking.
