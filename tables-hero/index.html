Tables Hero Privacy Policy

Effective date: 2026-10-18 App: Tables Hero (com.sonith.tableshero), version 0.1.0 Developer: Sonith Contact: sonythm@gmail.com URL: https://sonythm.github.io/sonith-apps/tables-hero/

Short version

Tables Hero is a times tables app for children. Everything stays on the phone. The developer receives nothing. The Android build blocks the internet permission, so the app makes no network calls. There are no accounts, no ads, no analytics, no crash reporting, no tracking and no in-app purchases. Each player is only a nickname and a built-in picture.

Children's privacy

Tables Hero is designed for children aged about 6 to 12 and follows Google Play's Families policy.

  • No personal information is collected. The app does not ask for, and the developer never receives, a child's real name, email address, phone number, address, photo, voice, location or any device identifier.
  • Nickname only. A player is a nickname (up to 16 letters) and one of twelve built-in pictures. The app suggests using a nickname rather than a real full name, and refuses nicknames that look like an email address or contain long numbers such as a phone number.
  • No camera, no microphone. The camera and microphone permissions are blocked in the app.
  • No ads and no third-party code that collects data. There is no advertising SDK, no analytics SDK, no crash reporter and no social login. The advertising ID permission is blocked.
  • No links out, no sharing, no purchases for children. The child-facing screens contain no web links, no share buttons, no chat, no other users and nothing to buy.
  • Parent gate. Settings, reminders, backup, reset and this privacy information sit behind a parent gate: press and hold for 3 seconds, then type a four-digit number that is written out in words. The parent area locks again when you leave it, after 10 minutes, or after a minute away from the app.
  • Parental rights. Because nothing is sent to the developer, there is no copy to review or delete on our side. A parent can review, export and delete all of a child's data on the phone (see "How to delete your data").

Tables Hero complies with the US Children's Online Privacy Protection Act (COPPA) and the UK Age Appropriate Design Code by not collecting personal information from children at all.

What the app stores on the device

  • Players: nickname, chosen picture, the date the player was added, the badges earned (with the day), and the settings a parent chose (daily goal, tables used, add and take away range).
  • Practice rounds: for each round, the game type, the day, how long it took, the questions, the answers typed, whether each was right, and the time taken to answer.
  • Fact progress: for each fact (for example 7 × 8), how often it was tried and answered right, a learning level (1 to 5), the typical answer time and the day it was last practised.
  • Settings: sounds, vibration, and reminder time and quiet hours.

This data is kept in a local database (SQLite) in the app's private storage, which other apps cannot read.

Network calls

None. The internet permission is blocked in the app. The font and the sounds are bundled inside the app. The privacy policy address is shown as text in the parent area. The app does not open it.

Permissions

  • Notifications (POST_NOTIFICATIONS): only if a parent turns on the daily practice reminder. Reminders are scheduled on the phone, with no push server. The reminder text is generic ("Time for Tables Hero!") and never shows a child's nickname.
  • Vibrate, run at start-up, wake lock, modify audio settings: added by the vibration, notification and sound libraries so that vibration works, reminders survive a restart and sounds play.
  • Blocked: internet, camera, microphone, location, contacts, storage, advertising ID, drawing over other apps and push messaging.
  • Backup import uses the Android system file picker, so the app needs no storage permission.

Backups

Android's automatic cloud backup is switched off for this app (allowBackup is false). In the parent area, Export backup saves a file and opens the Android share sheet so a parent can keep it. The file contains the players' nicknames and progress. It leaves the phone only if the parent chooses where to send it, and the developer never receives it. Import backup replaces the data on the phone with a backup file the parent picks.

How to delete your data

  • In the parent area, open a player to reset their progress or remove the player.
  • In the parent area, Settings, then Delete all data, removes every player and cancels reminders.
  • Uninstalling the app, or clearing its storage in Android settings, removes everything, including exported files kept in app storage.
  • Backup files a parent has saved elsewhere must be deleted there.

The developer holds no copy, so there is nothing to request from the developer.

Changes

If this policy changes, the new version will be posted at the same address with a new effective date. Because the app collects no personal information, a change will never start collecting it without a new app version and an updated policy.
