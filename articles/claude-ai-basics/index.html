The basics to understand before you use Claude seriously

Prompts, system prompts, the context window, tools, agents, thinking and hallucination explained in everyday language, with a glossary.

Part 1 explained what Claude is. This part gives you the handful of ideas that make everything else easier. Once you understand these, advice about "how to prompt" stops feeling like magic and starts feeling like common sense.

1. The prompt is everything Claude sees

When you chat with Claude, your message is only part of what it reads. A request is built from several pieces:

  • The system prompt: standing instructions, often written by whoever built the product ("You are a friendly tutor. Keep answers short.").
  • The conversation so far: every earlier message from you and from Claude.
  • Anything you attach: documents, images, pasted text.
  • The results of any tools Claude used along the way.

Anthropic's documentation says all of this counts toward the limit: the system prompt, every message, tool results, images and documents, and the tool definitions. The reply Claude writes counts as well. Keep that picture in mind, because it explains most surprises.

In plain words

Claude has no memory of you beyond the page it is handed. Each time it answers, it re-reads the whole page. If something is not on the page, as far as Claude is concerned, it does not exist.

2. System prompts and roles

A system prompt sets the scene before the conversation starts. Anthropic's own guidance says that giving Claude a role in the system prompt focuses its behaviour and tone, and that even a single sentence makes a difference. When you use a ready-made product, someone else has usually written the system prompt for you. When you build your own tool, or use a feature that lets you set standing instructions, you write it yourself.

3. The context window: the desk

The context window is how much Claude can hold in view at one time, measured in tokens (small pieces of text, explained fully in part 5). Anthropic's documentation describes it as a kind of working memory, different from the huge body of text the model was trained on.

For the current Claude models the window is up to 1 million tokens, which the documentation puts at roughly 555,000 words. That sounds endless, but there is a catch. The same page says that more context is not automatically better: as the amount of text grows, accuracy and recall can degrade, an effect it calls context rot. So the skill is not stuffing everything in, but choosing what belongs on the desk.

Key idea

A bigger context window is a bigger desk, not a better memory. Put the right papers on it, not all the papers.

4. Models: pick the right size

Anthropic currently offers four models: Fable 5.1, Opus 5.5, Sonnet 5.5 and Haiku 5.5. In rough terms: Haiku is fastest, Sonnet balances speed and intelligence, Opus is for long-running coding and knowledge work, and Fable is for the hardest reasoning. A small task does not need the biggest model, and a hard task is a poor fit for the smallest. Part 4 shows how the choice affects cost.

5. Thinking

Current Claude models can think before answering, which means working through reasoning steps first. Anthropic's documentation says that with adaptive thinking the model decides how much thinking a task needs, so harder questions get more. This thinking uses tokens too, and it is billed as output.

6. Tools

On its own, Claude only produces text. Tools let it do more: search the web, run code, read a file, call another program. Anthropic's documentation mentions web search and code execution as tools its models can use, among others. When Claude uses a tool, the tool's result comes back onto the page, and Claude carries on from there.

7. Agents

An agent is Claude in a loop with tools. You give it a goal, and it works step by step: look, plan, act, check. The more steps, the more important it is to review the work. Part 6 covers the agent tool Claude Code and how to use it safely.

8. Hallucination and honesty

Claude sometimes states things that are false with complete confidence. Anthropic says its latest models are less prone to hallucination than earlier ones, and its guidance for coding use includes a prompt that tells Claude to read the relevant files before answering and not to make claims about code it has not looked at. Still, "less prone" is not "never".

Three simple habits help:

  1. Ask for the exact quote or source when you need a fact.
  2. Ask Claude to say when it is unsure.
  3. Verify anything you will act on.

9. The same question can give different answers

Ask the same thing twice and you may get differently worded replies. That is normal. If you need the same format every time, say exactly what format you want, and show an example. Part 3 shows how.

Real example

Prompt: "Summarise this meeting." The first reply is five bullets, the second is two paragraphs. Prompt: "Summarise this meeting as exactly three bullets: decision, owner, deadline." Now the format barely varies.

Putting it together

When a result disappoints, check the page Claude saw. Was the goal clear? Was the right information there? Was there too much unrelated material? Was the model suited to the task? Was a tool missing? Most problems are on that list.

Glossary
Token
A small piece of text, a word or part of a word, that the model reads and writes.
System prompt
Standing instructions given before the conversation starts.
Context window
The amount of text the model can hold in view at once.
Context rot
Anthropic's term for accuracy dropping as the amount of context grows.
Tool
Something Claude can call, such as web search or running code.
Agent
Claude working in a loop with tools toward a goal.
Adaptive thinking
The model decides how much reasoning to do before answering.
Hallucination
A confident but false statement.

Frequently asked questions

Does Claude learn from my chat?

Within a conversation it uses what is on the page. Whether your chats are used to improve models depends on your plan and settings, so read the privacy settings of the product you use.

Why does Claude seem to forget things from earlier in a long chat?

Long chats fill the context window, and quality can drop as it grows. Summarise and start a fresh chat for a new phase of work.

Do I need to know any maths?

No. Everything in this series is about writing, organising and checking.
