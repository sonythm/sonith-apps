Claude pricing and plans explained

Plans for people and teams versus paying per token through the API, why input and output cost differently, and how caching and batching cut the bill. Prices checked on 21 October 2026.

  • Output tokens cost more than input tokens
  • Caching and batching can cut the bill

Reading level

There are two quite different ways to pay for Claude, and most confusion comes from mixing them up. This article explains both, shows the prices Anthropic lists today, and ends with a worked example. Each section has the plain picture first and an Expert view with the precise details.

Careful

Prices and plans change. Everything below was read from Anthropic's official pages on 2026-10-21. Treat the numbers as a dated snapshot and check the official pricing pages, linked at the end, before you decide anything.

Two ways to pay

Plans for people

Anthropic's pricing page lists these consumer plans. The page shows "$" without naming a currency and says prices exclude tax.

PlanPrice as shownWhat the page says
Free"$0"Chat on web, desktop and mobile, web search, file creation, code running and memory. Covers everyday questions.
Pro"$17" a month billed annually ("$200 billed up front"), or "$20" billed monthlyAt least five times the usage of Free per five-hour session, plus Claude Code, Projects and more models.
Max"From $100" a monthA choice of 5x or 20x the usage of Pro per five-hour session, higher output limits, priority access at busy times.
Expert viewReading usage limits

Anthropic says all plans have usage limits, and that paid plans add weekly limits. Pro, Max and Team can buy extra usage credits and keep working. Usage depends on the model and the task, which is why long agentic coding sessions use a plan up faster than short chats. The exact limits are not published as fixed numbers on the pricing page; it describes them relatively (for example "at least 5x more usage per 5-hour session than Free"), so budget by observation and read the support articles for your plan.

Plans for teams and organisations

PlanPrice as shownNotes
Team, Standard seat"$20" per seat a month annually, or "$25" monthlyFor teams of 2 to 150, with central billing and single sign-on.
Team, Premium seat"$100" per seat a month annually, or "$125" monthlyFive times the usage of Standard seats.
Enterprise"US$20" per seat a month, billed annually, 20 seat minimumExtra controls such as audit logs and custom data retention. The page says usage is billed at API rates.

The API: paying per token

A token is a small piece of text (part 5 explains tokens). Anthropic prices per million tokens, written "MTok", in US dollars on the API pricing page.

ModelInput, per million tokensOutput, per million tokens
Claude Haiku 5.5$0.10 (prompts up to 100,000 tokens), $0.50 above that$0.50, or $2.50 above that
Claude Sonnet 5.5$2$10
Claude Opus 5.5$4$20
Claude Fable 5.1$10$50
Expert viewDetails around the base price

Anthropic's table lists the same base prices as above, plus cache write and cache hit prices. A few points it states: long-context requests on most current models are billed at standard rates, with Claude Haiku 5.5 as the exception (prompts over 100,000 tokens cost more, and the count includes cache reads and writes). Opus 5.5 has a fast mode at higher prices ($8 input and $40 output per MTok, listed as of this check). Specifying US-only inference on 4.6 and later models carries a 1.1x multiplier on all token prices. Models from Claude Opus 4.7 onward use a newer tokenizer that produces about 30 percent more tokens for the same text than earlier models, so always count with the model you plan to use.

Why input and output cost different amounts

Input tokens are everything you send: your message, the earlier conversation, attached files, instructions. Output tokens are what Claude writes, including its reasoning before answering. Output costs more per token. In the list above, output is five times the input price for each model.

In plain words

You pay to have Claude read, and you pay more for it to write. A long document with a short answer is cheaper than a short question with a long essay as the answer.

Two discounts worth knowing

Expert viewCache and batch arithmetic

Anthropic's pricing page lists cache multipliers relative to the base input price: a 5-minute cache write costs 1.25x, a 1-hour write costs 2x, and a cache read costs 0.1x in general (0.05x on Opus 5.5 and Sonnet 5.5, 0.025x on Fable 5.1). It says the 5-minute cache pays for itself after a single reuse and the 1-hour cache after two. Batch and caching discounts can be combined, and the multipliers stack with other modifiers such as data residency. The Batch API is asynchronous, so use it for work that does not need an immediate answer; fast mode is not available with it.

Which should I choose?

Plans are for people using Claude. The API is for software using Claude.

Glossary
MTok
One million tokens, the unit used on the API price list.
Input tokens
The text you send, including earlier conversation and attachments.
Output tokens
The text Claude writes, including its reasoning.
Prompt caching
Storing repeated text so reusing it costs much less.
Batch API
Asynchronous processing at a discount for work that is not urgent.
Usage limit
A cap on how much you can use within a time window on a plan.

Frequently asked questions

Is there a free way to try the API?

Anthropic's pricing page says new users receive a small amount of free credits to test the API.

Do the same words cost the same on every model?

The price per token differs by model, and newer tokenisers can produce about 30 percent more tokens for the same text. Count with the model you plan to use.

Will these prices stay the same?

Not necessarily. Anthropic's page says plans and prices may change.

Key takeaways

  • Plans are for people using Claude, the API is for software using Claude
  • Output tokens cost more than input tokens
  • Caching and batching can cut the bill
