Claude pricing and plans explained

Plans for people and teams versus paying per token through the API, why input and output cost differently, and how caching and batching cut the bill. Prices checked on 21 October 2026.

There are two quite different ways to pay for Claude, and most confusion comes from mixing them up. This article explains both, shows the prices Anthropic lists today, and ends with a worked example you can adapt.

Careful

Prices and plans change. Everything below was read from Anthropic's official pages on 2026-10-21. Treat the numbers as a dated snapshot and check the official pricing pages, linked at the end, before you decide anything.

Two ways to pay

  1. Plans: a monthly price for using Claude as an app (chat on web, desktop and mobile). This is what most people want.
  2. The API: for developers who build Claude into their own software. You pay for the amount of text processed, counted in tokens, with no monthly fee for the model itself.

Plans for people

Anthropic's pricing page lists these consumer plans (the page shows "$" without naming a currency, and says prices exclude tax):

  • Free"$0". Chat on web, desktop and mobile, web search, file creation, code running and memory. Described as covering everyday questions.
  • Pro"$17" a month when billed annually ("$200 billed up front"), or "$20" if billed monthly. At least five times the usage of Free per five-hour session, plus Claude Code, Projects and more models.
  • Max"From $100" a month. A choice of 5x or 20x the usage of Pro per five-hour session, higher output limits, and priority access at busy times.

All plans have usage limits. Paid plans also add weekly limits. The page says Pro, Max and Team can buy extra usage credits.

Plans for teams and organisations

  • Team, Standard seat"$20" per seat a month if billed annually, or "$25" if billed monthly. For teams of 2 to 150, with central billing and single sign-on.
  • Team, Premium seat"$100" per seat a month annually, or "$125" monthly, with five times the usage of Standard seats.
  • Enterprise"US$20" per seat a month, billed annually, 20 seat minimum, with extra controls such as audit logs and custom data retention. The page says usage is billed at API rates.

The API: paying per token

A token is a small piece of text. Part 5 explains tokens in detail. For pricing, you only need this: Anthropic prices per million tokens, written "MTok". Prices are in US dollars on the API pricing page.

Here are the base prices for the four current models as listed on the official API pricing page on 2026-10-21:

  • Claude Haiku 5.5$0.10 per MTok input, $0.50 per MTok output for prompts up to 100,000 tokens. Above that length, $0.50 and $2.50.
  • Claude Sonnet 5.5$2 per MTok input, $10 per MTok output.
  • Claude Opus 5.5$4 per MTok input, $20 per MTok output.
  • Claude Fable 5.1$10 per MTok input, $50 per MTok output.

Why input and output cost different amounts

Input tokens are everything you send: your message, the earlier conversation, attached files, instructions. Output tokens are what Claude writes, including the reasoning it does before answering. Output costs more per token than input. In the list above, output is five times the input price for each model.

In plain words

You pay to have Claude read, and you pay more for it to write. A long document with a short answer is cheaper than a short question with a long essay as the answer.

Two discounts worth knowing

Prompt caching. If you send the same big chunk of text again and again, such as a long set of instructions or a document, Anthropic can store it and charge much less when it is reused. According to the pricing page, a cache read costs a fraction of the normal input price: 0.1 times the base price in general, and less on some models (0.05 times for Opus 5.5 and Sonnet 5.5). Storing it in the first place costs a little more, 1.25 times the input price for a five-minute cache. The page says the 5-minute cache pays off after a single reuse.

Batch processing. If an answer is not needed immediately, the Batch API offers a 50 percent discount on both input and output tokens. The page says batch and caching discounts can be combined.

A worked example (illustrative arithmetic)

Suppose a request sends 10,000 input tokens and gets 1,000 output tokens back, on Claude Sonnet 5.5, using the prices above.

  • Input: 10,000 tokens is 0.01 MTok, at $2 per MTok is $0.02.
  • Output: 1,000 tokens is 0.001 MTok, at $10 per MTok is $0.01.
  • Total: $0.03 for that request.

Run it a thousand times and it is about $30. The same request through the Batch API would be half that. This is just arithmetic to show the shape of the cost. Your real numbers depend on your own text. Part 5 includes a small calculator where you enter the rates yourself.

Which should I choose?

  • Just want to chat, write and learn? A plan. Start free, move to Pro if you hit limits.
  • Using it all day, for coding or long work? Look at Pro or Max, and read how usage limits work on the official page.
  • A team? The Team plans give central billing and shared controls.
  • Building software? The API, with the right-sized model and caching.
Key idea

Plans are for people using Claude. The API is for software using Claude. They are priced differently because they are used differently.

Glossary
MTok
One million tokens, the unit used on the API price list.
Input tokens
The text you send, including earlier conversation and attachments.
Output tokens
The text Claude writes, including its reasoning.
Prompt caching
Storing repeated text so reusing it costs much less.
Batch API
Asynchronous processing at a discount for work that is not urgent.
Usage limit
A cap on how much you can use within a time window on a plan.

Frequently asked questions

Is there a free way to try the API?

Anthropic's pricing page says new users receive a small amount of free credits to test the API.

Do the same words cost the same on every model?

The price per token differs by model, and Anthropic notes that newer tokenisers can produce about 30 percent more tokens for the same text on some models. Count with the model you plan to use.

Will these prices stay the same?

Not necessarily. Anthropic's page says plans and prices may change.
