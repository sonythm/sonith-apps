Chat answers a question. An agent does a job. Claude Code is Anthropic's agent for software work, and it changes how people build apps. This part explains what it does, in plain language, and how to keep control while it works. Written for builders and curious beginners alike.

What is Claude Code?

Anthropic describes Claude Code as an agentic coding tool that reads your codebase, edits files, runs commands and integrates with your development tools. A codebase is the folder of files that make up a piece of software. It is available in a terminal, in code editors such as VS Code and the JetBrains family, in a desktop app and in a browser. Most of these need a Claude subscription or an Anthropic Console account.

According to Anthropic's overview, you can describe what you want in plain language. Claude Code plans the approach, writes code across several files, and verifies that it works. For a bug, you can paste an error message and it traces the cause and proposes a fix.

The agent loop

A good agent works in a loop. It reads the relevant files, makes a plan, changes things, then checks the result, for example by running the tests. If the check fails, it goes round again. This is why agents can finish bigger jobs than a single chat answer. It is also why review matters more: more happens between your request and the result.

In plain words

Chat is like asking a colleague a question. An agent is like handing them a task and a key to the office. You want to know what they did with the key.

What can it do?

From Anthropic's overview, among other things:

  • Write tests, fix lint errors, update dependencies and write release notes.
  • Build features and fix bugs from a plain-language description.
  • Work with git: stage changes, write commit messages, create branches and open pull requests.
  • Connect to other tools through the Model Context Protocol, an open standard for linking AI tools to data sources.
  • Run several agents in parallel, with a lead agent coordinating, and run tasks on a schedule.

Standing instructions: CLAUDE.md

Claude Code reads a file called CLAUDE.md at the start of every session. Put your standards there once: coding style, architecture decisions, preferred libraries, review checklist. Anthropic also describes skills, which package repeatable workflows, and hooks, which run commands before or after Claude Code actions, such as auto-formatting after every file edit.

Permissions: your safety rail

Claude Code uses a tiered permission system, according to Anthropic's documentation. In its default manual mode:

  • Reading files inside your project does not need approval.
  • Running shell commands asks first, apart from a built-in set of read-only commands.
  • Editing or writing files asks first.
  • Fetching web pages asks first, apart from a set of pre-approved documentation sites.

When it asks, the prompt shows what Claude is about to do, and your options include "yes, and don't ask again" for that kind of action. You can also write allow and deny rules, and share them with your team. The documentation describes several permission modes that change what asks and what does not.

Key idea

Every approval you grant widens what the agent can do on its own. Widen it slowly, for tasks and places you trust.

A safe working routine

  1. Work in version control. Keep your project in git so every change can be reviewed and undone.
  2. Start small. Ask for one focused change, not the whole app.
  3. Ask for a plan first, then approve it.
  4. Read the changes. Review the diff before accepting. Treat it like a colleague's pull request.
  5. Run the tests, and ask Claude to write tests for new behaviour.
  6. Keep secrets out. Never paste passwords, keys or private data into prompts or into files the agent can read.
  7. Be careful with untrusted content. Text from a web page or a file can contain instructions meant to trick an agent, called prompt injection. Anthropic says Opus 5.5 is more resistant than its predecessor, which is progress, not a guarantee.
  8. Commit often so you always have a clean place to return to.
Careful

Do not give an agent permission to run commands you do not understand, on a machine that holds things you cannot afford to lose.

Prompts that work well with an agent

Goal: add a "mark as paid" button to the invoice screen.
Constraints: follow the existing code style; do not change the database format.
First, read the relevant files and tell me your plan. Wait for my OK.
After the change, run the tests and tell me what you checked.

Anthropic's guidance for coding also includes telling Claude to investigate files before answering questions about them, instead of guessing.

Where to learn more

The Claude Code documentation has a quickstart and common workflows, and Anthropic points to free self-paced courses at Claude Academy. Try a small project on a copy of your code first.

Glossary
Agent
Claude working in a loop with tools toward a goal.
Codebase
The collection of files that make up a software project.
Diff
A view of exactly what changed in the files.
Pull request
A proposed change that others review before it is merged.
MCP
Model Context Protocol, a standard for connecting AI tools to other software and data.
Hook
A command that runs automatically before or after an agent action.
Prompt injection
Hidden instructions in content that try to steer an AI agent.

Frequently asked questions

Do I need to be a programmer to use Claude Code?

It helps. You do not need to write every line, but you need to read and judge the result, or have someone who can.

Can it break my project?

Any tool that edits files can. Version control and review are your protection.

Is it only for code?

It is designed for software work. The idea of an agent with tools reaches beyond it.
