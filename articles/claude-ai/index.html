Claude AI: from first steps to mastery

A ten-part, picture-led path from what Claude is, through prompts, plans, pricing and tokens, to context, CLAUDE.md, skills, sharing with a team and Claude Code.

Start here

Read the parts in order if you are new, or jump to the one you need. Facts about models, plans and prices were checked against official Anthropic pages on 2026-10-21 and are linked at the end of each part.

    What is Claude AI? A plain-language guide

    What Claude Code is, how an agent loop works, which permissions protect you, how skills, subagents, hooks and MCP fit in, and a safe working routine.
