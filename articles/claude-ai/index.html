Claude AI: from first steps to mastery

A twelve-part, picture-led path from what Claude is, through prompts, plans, pricing and tokens, to context, CLAUDE.md, skills, sharing with a team, MCP versus APIs, Claude Code and a map of the wider AI tools landscape.
